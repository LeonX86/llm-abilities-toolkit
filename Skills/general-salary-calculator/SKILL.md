# 通用薪资计算器

## 第一步：参数完整性检查

计算需要**税前工资**；其余参数缺省时按默认值处理，无需反复追问：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 税前工资 | 每月税前月薪（元） | 无，必须提供 |
| 社保基数 | 个人社保缴费基数 | 与税前工资相同（足额） |
| 社保比例 | 个人社保缴纳比例 | 10.5%（0.105） |
| 公积金基数 | 个人公积金缴费基数 | 与税前工资相同（足额） |
| 公积金比例 | 个人公积金缴纳比例 | 12%（0.12） |

用户说「足额」「按工资缴」等，表示基数 = 税前工资。比例可写 `10.5%`、`12%` 或小数 `0.105`、`0.12`。

---

## 第二步：参数提取

| 参数 | 类型 | 说明 |
|------|------|------|
| `salary` | 数字 | 税前月工资。`10k`→`10000`，`2w`→`20000`，`1.5万`→`15000` |
| `social_base` | 数字 | 社保基数，未提及则等于 `salary` |
| `social_rate` | 小数 | 社保个人比例，未提及则 `0.105` |
| `fund_base` | 数字 | 公积金基数，未提及则等于 `salary` |
| `fund_rate` | 小数 | 公积金个人比例，未提及则 `0.12` |

---

## 第三步：运行计算脚本

参数确定后，在技能目录下执行（仅需传入非默认参数）：

```bash
python scripts/calc_salary.py --salary {salary}
```

**示例：**

```bash
python scripts/calc_salary.py --salary 20000
python scripts/calc_salary.py --salary 30000 --social-base 25000 --social-rate 0.105 --fund-base 25000 --fund-rate 0.12
```

脚本输出 JSON，主要字段：

| 字段 | 含义 |
|------|------|
| `pre_tax_salary` | 税前月工资 |
| `avg_after_tax` | 全年平均税后月工资 |
| `monthly_social` | 每月个人社保 |
| `monthly_fund` | 每月个人公积金 |
| `table_md` | 全年 12 个月收入明细 Markdown 表格 |

计算规则：
- 个税采用**累计预扣法**（与实际发薪一致），每月基本减除费用 5000 元
- 适用现行七级超额累进税率（3%～45%）
- 当月税后工资 = 税前 − 社保 − 公积金 − 当月个税

---

## 第四步：向用户输出结果

按以下**固定顺序**输出，**不要用代码块包裹** Markdown 表格。

### 1. 汇总信息（单独列出）

依次输出以下四项（金额保留两位小数，加千分位）：

- **税前工资**：`{pre_tax_salary}` 元/月
- **平均税后工资**：`{avg_after_tax}` 元/月
- **每月社保**：`{monthly_social}` 元/月
- **每月公积金**：`{monthly_fund}` 元/月

在「每月公积金」后紧跟一行提醒：

> 公积金为**双边缴纳**，个人账户实际入账约为个人部分的 **2 倍**（即约 `{monthly_fund × 2}` 元/月），具体以单位政策为准。

### 2. 收入明细表格

直接输出脚本返回的 `table_md`，表头为：

| 月份 | 当月税前工资 | 当月社保 | 当月公积金 | 当月个税 | 当月税后工资 | 累积税前工资 | 累积社保 | 累积公积金 | 累积个税 | 当月个税比例 |

其中「当月个税比例」列展示**当月个税的阶梯计算公式**（LaTeX），说明本月新增应纳税所得额落在哪个税率档、如何算出当月个税，公式最终结果必须等于「当月个税」列。规则：

- 未跨档：$10500 \times 3\% = 315$（金额为当月新增应纳税所得额，即税前 − 社保 − 公积金 − 5000）
- 跨档升档：多段相加，如 $4500 \times 3\% + 6000 \times 10\% = 135 + 600 = 735$

用户：「我月薪 2 万，足额缴五险一金，帮我算到手多少」

执行 `python scripts/calc_salary.py --salary 20000`，然后输出：

**税前工资**：20,000.00 元/月  
**平均税后工资**：（脚本结果） 元/月  
**每月社保**：2,100.00 元/月  
**每月公积金**：2,400.00 元/月  

> 公积金为**双边缴纳**，个人账户实际入账约为个人部分的 **2 倍**（即约 4,800.00 元/月），具体以单位政策为准。

（随后输出 `table_md` 全年明细表）
