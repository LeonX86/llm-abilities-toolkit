# 时薪计算器

## 第一步：参数完整性检查

时薪计算需要以下四个参数**全部具备**，缺一则直接询问用户补全，不继续执行：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 月薪 | 每月工资金额 | 无，必须提供 |
| 上班时间 | 每天上班时刻 | 上午9点（9） |
| 下班时间 | 每天下班时刻 | 下午6点（18） |
| 每周工作天数 | 每周上班天数 | 5天 |

### 快捷作息码解析

用户可能用数字串表示作息，格式为 `上班时` + `下班时(原始)` + `每周天数`，下班时间 ≤ 12 则视为下午，+12 转为24小时制：

| 输入 | 上班 | 下班（24h） | 每周天数 |
|------|------|-------------|----------|
| 955  | 9    | 17          | 5        |
| 996  | 9    | 21          | 6        |
| 965  | 9    | 18          | 5        |
| 966  | 9    | 18          | 6        |
| 10107| 10   | 22          | 7        |

---

## 第二步：参数提取

| 参数 | 类型 | 说明 |
|------|------|------|
| `salary` | 数字 | 月薪金额。`10k`→`10000`，`2w`→`20000` |
| `work_time` | 数字（24h制） | 上班时刻，"早上9点"→`9` |
| `off_time` | 数字（24h制） | 下班时刻，"下午6点"→`18`，作息码下班时间≤12则+12 |
| `week_days` | 数字 | 每周工作天数，未提及默认`5` |
| `month_in_prompt` | 字符串 | 有明确月份→`2026-05`；只有月份→拼当前年；未提及→`0` |

---

## 第三步：运行计算脚本

参数提取完毕后，执行：

```bash
python scripts/calc.py --salary {salary} --work-time {work_time} --off-time {off_time} --week-days {week_days} --month {month_in_prompt}
```

**示例：**

```bash
python scripts/calc.py --salary 15000 --work-time 9 --off-time 18 --week-days 5 --month 0
```

脚本输出 JSON，包含以下字段：

| 字段 | 含义 |
|------|------|
| `month_str` | 计算月份，如 `2026-05` |
| `total_days` | 当月总天数 |
| `work_days` | 当月工作日天数（含补班，排除节假日） |
| `rest_days` | 当月休息日天数 |
| `rest_day_list` | 休息日列表（含节假日、周末） |
| `makeup_day_list` | 补班日列表（原本是周末但需要上班的日期） |
| `daily_work_hours` | 每日工作时长（小时） |
| `monthly_work_hours` | 当月总工作时长（小时） |
| `hourly_rate` | **时薪（元/小时）** |

> 脚本依赖 `requests`，需确认已安装。节假日数据来源于 [timor.tech](http://timor.tech/api/holiday)，API 不可用时自动回退到按星期计算。

## 第四步：以 Markdown 格式输出结果

根据脚本输出的 JSON，直接以 Markdown 输出以下三部分（**不要用代码块包裹**）：

### 1. 参数与结果汇总表

| 项目 | 数值 |
|------|------|
| 月薪 | `{salary}` 元 |
| 上班时间 | 早上 `{work_time}` 点 |
| 下班时间 | `{off_time}` 点（24小时制） |
| 每周工作天数 | `{week_days}` 天 |
| 计算月份 | `{month_str}` |
| 当月总天数 | `{total_days}` 天 |
| 当月休息日 | `{rest_days}` 天 |
| 当月工作日 | `{work_days}` 天 |
| 每日工作时长 | `{daily_work_hours}` 小时 |
| 当月总工作时长 | `{monthly_work_hours}` 小时 |
| **时薪** | **`{hourly_rate}` 元/小时** |

### 2. 计算过程（LaTeX 公式）

用连等号将公式与具体数值一起展示，例如月薪15000、9点上班、18点下班、当月22个工作日：

$$
\text{每日工作时长} = \text{下班时间} - \text{上班时间} = 18 - 9 = 9 \text{ 小时}
$$

$$
\text{当月总工作时长} = \text{每日工作时长} \times \text{当月工作日天数} = 9 \times 22 = 198 \text{ 小时}
$$

$$
\text{时薪} = \frac{\text{月薪}}{\text{当月总工作时长}} = \frac{15000}{198} \approx 75.76 \text{ 元/小时}
$$

**输出时将示例中的数字替换为用户的实际数值。**

### 3. 当月休息日与补班

用紧凑的单行列表格式展示，各占一行：

```
休息日：['2026-05-01', '2026-05-02', '2026-05-03', ...]
补班日：['2026-04-27']   # 若为空则输出 []
```
